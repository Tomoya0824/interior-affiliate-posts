# Room Totonoe 投稿文の書き方

毎朝の定期実行でClaudeが読むルールです。候補商品の中から1つを選び、Threadsに載せる投稿文を書きます。

## アカウントの立ち位置

- 「おしゃれな家具・照明・インテリア雑貨で、部屋を垢抜けさせる」アカウント（2026-11-09 に方向転換。それまでは収納・寝具・キッチン用品中心）
- 読み手は、ワンルームや2LDKくらいの部屋で「おしゃれな部屋にしたいのに、なんだか垢抜けない」「何を足せばいいかわからない」と悩んでいる人
- 目指すのは「広告っぽい商品紹介」ではなく「部屋づくりに詳しい人の、気の利いたおすすめ」。投稿を読んだあと、自分の部屋で今日すぐ1つ試せること
- 口調は丁寧すぎない「です・ます」。友人に教えるくらいの温度感。絵文字は使わないか、1つまで

## いちばん大事なこと：ひとりの暮らしを思い浮かべて書く

投稿は「みんな」に向けて書かない。毎回、下の「暮らしの人物」から1人を選び、その人のある日のある瞬間を具体的に思い浮かべてから書く。読んだ人が「これ、私のことだ」と感じる一場面を切り取ることで、共感が生まれ、商品が「自分の暮らしに必要なもの」に見えてくる。

### 本文の組み立て（商品紹介）

本文は100〜140文字（短いほうが最後まで読まれる。Threadsは全体で500文字まで）。

1. **共感の一場面（1〜2文）**：選んだ人物の「ある瞬間」を、時間・場所・小さな気持ちまで具体的に描く。商品名から始めない
   - 例（solo-remote × 毛布）：「在宅勤務の日、夕方になると足もとからじわじわ冷えてきて、エアコンの温度を上げるか迷う。」
   - 例（dog-1ldk × 椅子脚カバー）：「椅子を引くたびに響くガガッという音。下の階に聞こえていないか、少し気になる夜。」
   - 例（dual-kids × 収納）：「子どもが寝たあと、床のおもちゃを拾い集めるところから始まる、自分の時間。」
2. **その場面がこう変わる（1〜2文）**：商品説明（caption・catchcopy・name・sizes）にある事実だけを使って、さっきの場面（部屋の見え方）が具体的にどう変わるかを描く。「この家具を置くと、その一角がこうなる」という姿が浮かぶように
   - 素材・色・形・サイズ（高さ・幅など）、置き方。数字が1つあると説得力が出る
   - 「どこに・どう置くか」の具体策を1つ入れる（例：ソファの横に、座面と同じくらいの高さで）
3. **背中を押す一言（任意・1文）**：選び方のコツ、あるいは「〇〇な人は△△タイプを」といった具体的な提案

### 共感を生むためのコツ

- 気持ちは大げさにしない。「ちょっと気になる」「毎回少し面倒」くらいの小さな本音が一番共感される
- 説明するより、場面を見せる（「寒い」より「指先が冷えてキーボードを打つ手が止まる」）
- 人物の年齢や属性を本文に書き並べない。場面から自然に伝わるようにする
- 文の最後は言い切りすぎず、余韻を残す

### 人物を使うときの守ること

- 人物はあくまで「場面を想像するための設定」。実在の人の話や購入者の声として書かない
  - NG：「30代の〇〇さんは、これを買ってから毎晩ぐっすり」「愛用者の声：…」
  - OK：「〜な夜。」「〜していませんか。」のように、読み手が自分を重ねられる書き方
- 紹介者（このアカウント）が使ったように書かない（下の「絶対に書かないこと」を参照）

## 絶対に書かないこと

- **使った体験の捏造**：「使ってみたら」「我が家では」「買ってよかった」など、実際に使ったように見える書き方はしない（紹介者の立場で書く）
- **体への効果**：「肩こり」「腰痛」「快眠」「安眠」「疲れがとれる」「健康に」「痩せる」など、体や健康に効くと受け取れる表現（薬機法）。寝具は素材・厚み・手入れ・サイズで紹介する
- **言い切りの誇張**：「最強」「絶対」「一番」「間違いない」「神アイテム」
- **データにない情報**：レビューの中身、売上順位、在庫・セール・クーポン情報、送料の有無
- **価格の断定**：価格は投稿の下にApps Scriptが自動で付けるので、本文には書かない
- 本文に「#PR」、リンク、ハッシュタグは書かない（自動で付く）

## ハッシュタグ（hashtags）

2〜3個。商品と関係あるものだけ。人気でも関係のないタグは付けない（楽天のスパム規定）。

候補：#インテリア #部屋づくり #おしゃれ家具 #インテリアコーディネート #照明 #見せる収納 #北欧インテリア #在宅勤務 #犬のいる暮らし #一人暮らし #暮らしを整える #収納アイデア #寝室 #冬支度

## 商品の選び方

候補が3つあるので、次の順で1つ選ぶ。

1. 季節外れの商品（冬に冷感グッズなど）は選ばない
2. 見た目で選ばれる商品（家具・照明・ミラー・インテリア雑貨）を優先する。寝具・掃除用品・消耗品など「おしゃれな部屋づくり」から遠いものは避ける
3. 説明文から具体的な特徴（素材・色・形・サイズ）を3つ以上読み取れる商品を優先する
4. 「暮らしの人物」のだれかの一場面がはっきり浮かぶ商品を優先する
5. 直近7日の投稿と同じ種類（例：照明が続く）は避ける

どれも説明が乏しい場合は、商品名から読み取れる事実だけで短めに書く。

## 出力の形式

`queue/posts/YYYY-MM-DD.json` に、次の形で保存する。

```json
{
  "date": "2026-11-08",
  "code": "候補の code をそのまま",
  "persona": "solo-remote",
  "scene": "在宅勤務の夕方、足もとが冷えてくる",
  "body": "本文（100〜140文字）",
  "hashtags": ["#収納", "#部屋づくり"]
}
```

## お役立ち投稿（毎日12時台・リンクなし）

商品紹介だけが続くと「宣伝アカウント」に見え、楽天のスパム規定にも触れやすくなる。そこで毎日1本、リンクも商品名もない「暮らしのコツ」を投稿する。これがフォローされる理由になり、夜の商品紹介が届く人を増やす。

- **本文は140文字以内**（目安は100〜140文字）。短く、1回で読み切れる長さにする
- テーマは「部屋を垢抜けさせる」こと：家具の配置・照明・色の合わせ方・飾り方・見せる収納・部屋が広く見える工夫・季節のしつらえ から1つ
- 対象は「おしゃれな部屋にしたいのに、うまくいかない」と悩む人。「暮らしの人物」から1人を選び（夜の商品紹介とは別の人物にする）、その人の悩みの一場面から書き出す
- 組み立ては **冒頭＝共感 → 本文＝具体策 → 問いかけ**
  - 冒頭（1文）：抽象的な悩み（「部屋がおしゃれにならない」）ではなく、目に見える一場面（「家具を買い足すたびに、部屋がなんだか雑多に見えていく」）
  - 具体策（1〜2文）：読者が今日から実践できる解決策を1つ。手順や数字（cm、色の数、個数）を入れる（例：「床に置く物の色を、家具と同じ3色までにしぼる」）
  - 最後：返信したくなる短い問いかけ（例：「みなさんの部屋は何色ですか？」）
- 誰でも知っている一般論だけで終わらせない
- 商品名・ブランド名・リンク・#PR・価格は書かない。夜の商品と同じテーマでなくてよい
- 体への効果、誇張、使った体験の捏造の禁止は商品紹介と同じ
- 直近7日の queue/tips/ と同じテーマ・同じ切り口を続けない
- 確認できない事実は断定しない。素材の効果・数値の根拠・「〇〇と言われています」のような豆知識は書かない。迷ったら、配置や色の工夫など、事実確認の要らない「やり方」にする

### 書いたあとの見直し（毎回）

書き終えたら、次の3点を見直してから保存する。

1. **重複**：直近の投稿（queue/tips/・queue/posts/、ストック分も含む）と、テーマ・冒頭の場面・具体策が重なっていないか
2. **抽象的な表現**：「おしゃれに」「すっきり」「いい感じに」だけで終わっていないか。冒頭を目に見える場面に、具体策を数字や手順にする
3. **事実確認が必要な情報**：確認できない事実を断定していないか。あれば削るか、やり方の話に言い換える

### ストック

queue/tips/ には、先の日付の分まで書きためてあることがある（2026-11-10〜2026-12-09 の30本）。その日のファイルが既にあれば、新しく書かない。

`queue/tips/YYYY-MM-DD.json` に、次の形で保存する。

```json
{
  "date": "2026-11-08",
  "theme": "玄関の片付け",
  "persona": "dual-kids",
  "body": "本文（140文字以内。冒頭は共感、具体策を1つ、最後は問いかけ）",
  "hashtags": ["#収納アイデア", "#暮らしを整える"]
}
```
